Compilation Workflow & Local Hosting

To compile the Mission-Sardine C++ code directly into WebAssembly and host it locally:

1 Compile to WASM

Run the compile script from the workspace directory:

web\compile.bat

This uses Emscripten to compile shell.cpp, embeds standard library modules, and exports required methods.

2 Start Local Server

Host the web folder on a local server. A simple Python command is sufficient:

cd web
python -m http.server 8000

3 Access in Browser

Open http://localhost:8000 in your browser. The page is automatically cross-origin isolated by the service worker, enabling high-performance features like blocking input.
